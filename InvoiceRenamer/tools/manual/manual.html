1증빙 모으기·정리

  1. 파일 가져오기로 인보이스 파일을 직접 보면서 고르거나(여러 개 가능), 폴더 가져오기로 인보이스가 든 폴더를 통째로 고르세요(하위 폴더 포함). PDF·사진·XRechnung XML이 작업 폴더(기본: 문서\월마감)에 복사되고 바로 읽혀요. 원본은 그대로 남아요. 같은 이름이 있으면 (2)를 붙여 덮어쓰지 않아요. 도구 → 환경설정에서 ‘이동’으로 바꿀 수 있어요.
  2. 빨간 행은 더블클릭(또는 편집)해서 빠진 값을 직접 입력하세요. 입력값은 저장 즉시 기록돼요. 한 번 고치면 그 업체 양식을 배워서 같은 업체의 다른 파일도 바로 채우고, 다음부터 자동으로 읽어요.
  3. 바꿀 행의 ☐를 눌러 체크하세요. 맨 위 ☑ 칸을 누르면 전체 선택·해제돼요. 그다음 파일명 변경을 눌러야 실제 파일 이름이 바뀌어요.
  4. 원본·내용 보기를 누르면 왼쪽에 PDF, 오른쪽에 읽어 낸 내용(마크다운)이 함께 보여요. 숫자가 맞는지 눈으로 확인하고, 필요하면 마크다운 파일로 저장하세요.

작업 폴더: 인보이스와 명세서는 모두 한 작업 폴더에 모여요. 처음 실행하면 문서\월마감을 만들고 열어요. 도구 → 환경설정에서 위치를 바꾸고 가져오기 방식(복사·이동)을 정해요. 더보기 → 작업 폴더 열기 (탐색기)로 폴더를 봐요. 파일을 옮기지 않고 다른 폴더를 그 자리에서 보려면 더보기 → 다른 폴더 열기(이전 방식).
업체마다 양식이 달라도 한 번만 고치면 돼요. 편집에서 저장하면 PDF 안에서 입력한 값 앞에 적힌 단어(예: ‘Ausgestellt am’, ‘Endsumme’)를 기억해요. 업체명은 PDF에 적힌 그대로 입력해야 배울 수 있어요. 배운 양식은 더보기 → 배운 인보이스 양식에서 보고, 잘못 배운 것은 지운 뒤 다시 고치세요.
파일명 변경을 누르면 이름을 바꾸면서 PDF 내용을 같은 이름의 마크다운(.md)으로 함께 저장하고, 끝나면 안내 팝업이 떠요. 파일을 옮길 때(매칭완료·중복·제외·되돌리기) 마크다운도 따라가요. 값을 고친 뒤 내용을 새로 맞추려면 더보기 → 마크다운 다시 만들기.

2명세서 불러오기

  • 은행·카드 명세서 추가: CSV나 PDF 한 개. 처음 쓰는 양식이면 날짜·가맹점·금액 열을 한 번 골라 주세요. 다음부터는 자동이에요.
  • 거래번호는 불러오는 순간 자동으로 붙어요. 611-001 = 2026년(6) 11월 첫 거래. 다시 불러와도 같은 번호예요.
  • PDF는 American Express, DKB, Deutsche Bank를 정확히 읽어요. 다른 은행은 CSV를 권해요.
  • 불러온 명세서 원본은 내용을 바꾸지 않고 작업 폴더 안 명세서/2026-11 같은 월 폴더에 복사돼요(환경설정에서 ‘이동’ 선택 가능). 같은 이름이 있으면 (2)를 붙여 덮어쓰지 않아요. 연습 모드에서는 옮기지 않아요.
  • 불러오기가 끝나면 거래 수와 함께 증빙 매칭으로 이동 → 버튼이 있는 안내가 떠요.
  • 더보기 → 명세서 양식 관리에서 저장된 양식을 카드·은행 이름별로 보고, 표시 이름을 바꾸거나 지울 수 있어요.

3증빙 매칭

  1. 왼쪽 거래 목록에서 거래를 고르세요. 위 칩(확인 필요·전체·증빙 없음·대조 완료)으로 걸러 볼 수 있어요.
  2. 오른쪽 추천 증빙 카드가 맞으면 연결을 누르세요. 다른 증빙이면 아래 표에서 골라 선택 연결을 누르세요.
  3. 찾는 증빙이 없으면 전체 증빙에서 고르기를 체크하세요. 나란히 보기로 명세서 거래와 인보이스를 함께 확인할 수 있어요.
  4. 증빙이 없으면 왼쪽 아래 메모·기록, 인보이스 요청 초안, Gmail 검색을 쓰세요. 카드대금·내부이체·환불은 증빙 없이 처리 ▾에 있어요.
  5. 다 끝나면 매칭완료 폴더로 이동을 누르고, 아래 다음 단계: 누락 점검 →으로 넘어가세요.
한 건씩 안 해도 돼요. 금액·날짜가 1:1로 맞는 후보가 있으면 위에 파란 띠가 나와요. 한 번에 연결하기를 누르면 후보 목록이 열리고, 업체명이나 번호까지 맞는 확실 후보는 미리 체크돼 있어요. 거의 일치 후보는 열어 보고 체크하세요. 연결된 거래는 확인 필요 목록에서 빠지고 대조 완료에서 볼 수 있어요.

메모·기록

세무사 전달 메모의 문구 버튼은 ✎ 문구 관리에서 추가·수정·삭제·순서 변경을 할 수 있어요. 버튼 이름은 한국어, 넣을 문구는 독일어로 적어요.

4누락 점검

세무사에게 보내기 전에 숫자가 모두 0인지, 0이 아니면 메모로 이유를 남겼는지 확인하세요.

5세무사 제출

  1. 세무사용 ZIP 만들기를 누르면 먼저 제출 범위를 골라요. 월·명세서를 체크하고, 뺄 거래는 체크를 해제하세요.
  2. 미리보기에서 내용을 확인하고 이 내용으로 ZIP 저장을 누르세요. 제출 범위와 미리보기 화면은 세무사에게 가는 독일어 표현과 한국어 뜻을 함께 보여 줘요(예: Beleg fehlt (증빙 없음)).
  3. 세무사에게 보낸 뒤 마감본 이력·전달 상태에서 ‘전달함’으로 표시하고, 월 마감 확정을 하세요.
  4. 나중에 증빙이 더 생기면 추가 제출 ZIP으로 바뀐 것만 보내요.

미리보기의 ZIP에 넣을 파일 탭에서 파일마다 한글 설명을 보고 넣을지 고를 수 있어요. 내용이 없는 표는 처음부터 빠져 있고, 필수 항목(증빙 폴더, 엑셀 대조표, 01_Abgleich.csv)은 뺄 수 없어요. 모든 표는 엑셀 파일 안에 시트로도 들어 있어요.

지난 달 보기·수정

  • 연결·메모·번호·제출 이력·변경 기록은 모두 저장돼 있어요.
  • 지난 달 열기에서 월을 고르면 그달 명세서를 다시 불러오고, 위쪽 월 선택도 그달로 바뀌어요.
  • 확정한 달은 월 마감 확정·재열기에서 사유를 적고 다시 열어야 수정할 수 있어요. 재열기 사유도 기록돼요.
  • 명세서 파일을 옮기거나 지우면 다시 불러올 수 없어요. 원본 명세서는 한 폴더에 보관하세요.

자주 묻는 질문

편집한 내용은 언제 저장되나요?

저장·연결 버튼을 누르는 즉시 %LOCALAPPDATA%\InvoiceRenamer에 저장돼요. 파일 이름만 ‘파일명 변경’을 눌러야 바뀌어요.

프로그램이 이미 열려 있으면?

다시 실행하면 새 창 대신 열려 있는 창이 앞으로 와요.

백업은?

도구 → 전체 작업 백업으로 기록과 첨부를 ZIP 한 개로 저장하세요. 다른 PC에서는 전체 작업 복원을 써요.

문제가 생기면?

도구 → 오류 진단 저장 파일을 보내 주세요. 거래·문서 내용·메모는 들어가지 않아요.
