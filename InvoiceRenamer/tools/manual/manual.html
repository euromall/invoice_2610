1증빙 모으기·정리

  1. 폴더 열기로 인보이스 PDF·사진·XRechnung XML이 있는 폴더를 고르세요.
  2. 빨간 행은 더블클릭해서 빠진 값을 직접 입력하세요. 입력값은 저장 즉시 기록돼요.
  3. 바꿀 행을 고르고 선택 항목 파일명 변경을 누르면 이름이 바뀌어요. 이 버튼을 눌러야 실제 파일 이름이 바뀌어요.
상태뜻할 일
변경 가능필수 항목을 다 읽음그대로 파일명 변경
필수 누락발행일·업체명·총액·번호 중 못 읽은 것이 있음더블클릭해서 입력
번호 없음250€ 이하 소액영수증 (§33 UStDV)영수증이면 그대로 둬도 됨
인보이스 아님 의심인보이스 단어가 거의 없음더보기 → 인보이스 아닌 파일 → 제외 폴더

새 이름 예: 58.39_26-11-25_greenist GmbH_Nr_R1044176_invoice.pdf

마크다운 저장은 저장 버튼이 아니라 PDF 내용을 텍스트(.md)로 내보내는 부가 기능이라 더보기에 있어요.

2명세서 불러오기

  • 은행·카드 명세서 추가: CSV나 PDF 한 개. 처음 쓰는 양식이면 날짜·가맹점·금액 열을 한 번 골라 주세요. 다음부터는 자동이에요.
  • 거래번호는 불러오는 순간 자동으로 붙어요. 611-001 = 2026년(6) 11월 첫 거래. 다시 불러와도 같은 번호예요.
  • PDF는 American Express, DKB, Deutsche Bank를 정확히 읽어요. 다른 은행은 CSV를 권해요.
  • 더보기 → 명세서 양식 관리에서 저장된 양식을 카드·은행 이름별로 보고, 표시 이름을 바꾸거나 지울 수 있어요.

3증빙 매칭

  1. 위 표에서 거래를 고르세요.
  2. 아래 표에서 증빙을 고르고 선택 연결을 누르세요.
  3. 증빙이 없으면 메모·기록, 인보이스 요청 초안, Gmail 검색을 쓰세요.
  4. 카드대금 자동이체·환불은 카드대금·내부이체 후보, 결제·환불 연결로 처리해요.
  5. 다 끝나면 매칭완료 폴더로 이동을 누르세요. 파일 이름 앞에 [611-001]_이 붙어요.

4누락 점검

세무사에게 보내기 전에 숫자가 모두 0인지, 0이 아니면 메모로 이유를 남겼는지 확인하세요.

5세무사 제출

  1. 세무사용 ZIP 만들기를 누르면 먼저 제출 범위를 골라요. 월·명세서를 체크하고, 뺄 거래는 체크를 해제하세요.
  2. 미리보기에서 내용을 확인하고 이 내용으로 ZIP 저장을 누르세요.
  3. 세무사에게 보낸 뒤 마감본 이력·전달 상태에서 ‘전달함’으로 표시하고, 월 마감 확정을 하세요.
  4. 나중에 증빙이 더 생기면 추가 제출 ZIP으로 바뀐 것만 보내요.

지난 달 보기·수정

  • 연결·메모·번호·제출 이력·변경 기록은 모두 저장돼 있어요.
  • 지난 달 열기에서 월을 고르면 그달 명세서를 다시 불러오고, 위쪽 월 선택도 그달로 바뀌어요.
  • 확정한 달은 월 마감 확정·재열기에서 사유를 적고 다시 열어야 수정할 수 있어요. 재열기 사유도 기록돼요.
  • 명세서 파일을 옮기거나 지우면 다시 불러올 수 없어요. 원본 명세서는 한 폴더에 보관하세요.

자주 묻는 질문

편집한 내용은 언제 저장되나요?

저장·연결 버튼을 누르는 즉시 %LOCALAPPDATA%\InvoiceRenamer에 저장돼요. 파일 이름만 ‘선택 항목 파일명 변경’을 눌러야 바뀌어요.

프로그램이 이미 열려 있으면?

다시 실행하면 새 창 대신 열려 있는 창이 앞으로 와요.

백업은?

도구 → 전체 작업 백업으로 기록과 첨부를 ZIP 한 개로 저장하세요. 다른 PC에서는 전체 작업 복원을 써요.

문제가 생기면?

도구 → 오류 진단 저장 파일을 보내 주세요. 거래·문서 내용·메모는 들어가지 않아요.
