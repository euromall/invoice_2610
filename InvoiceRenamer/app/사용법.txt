인보이스 PDF 파일명 변경

1. ZIP 압축을 풀고 Windows용 Python 3.10 이상을 설치하세요. 설치 옵션에 Tcl/Tk를 포함하세요.
   https://www.python.org/downloads/windows/
2. Start.bat을 더블클릭하세요. 첫 실행 때 PyMuPDF를 설치하므로 인터넷이 필요합니다.
3. PDF 폴더를 선택하면 현재 이름과 새 이름이 표시됩니다. '하위 폴더 포함'을 켜면 여러 단계 아래의 PDF도 표시합니다.
4. 확인이 필요한 행은 더블클릭해 발행일, 업체명, 총액을 입력하거나 수정하세요.
   날짜는 2026-11-25, 금액은 58.39 EUR 또는 58,39 EUR처럼 입력할 수 있습니다.
5. 바꾸려는 행을 선택한 다음 '선택 항목 파일명 변경'을 누르세요.
   Ctrl/Shift로 여러 행을 선택하거나 Ctrl+A로 전체를 선택할 수 있습니다.
   같은 이름이 있으면 확장자 앞에 (2), (3) 등의 번호를 붙입니다.

첫 실행에서 독일어·영어 OCR 언어 파일을 자동으로 내려받습니다.
별도의 Tesseract 설치는 필요 없습니다. 다운로드가 끝나면 OCR은 오프라인에서도 동작합니다.
다운로드에 실패하면 텍스트 PDF는 계속 처리할 수 있습니다. 인터넷에 연결한 뒤 Start.bat을
다시 실행하면 빠진 언어 파일을 받습니다. 한국어 OCR이 필요하면 kor.traineddata를
압축을 푼 폴더 안의 tessdata에 추가하세요.

텍스트와 스캔 이미지가 한 페이지에 섞인 경우에는 자동 인식이 일부 누락될 수 있습니다.

PDF는 컴퓨터 안에서 처리됩니다. Gmail에서 사용할 PDF는 먼저 폴더에 저장하세요.

카드 명세서 월 마감

• 카드사에서 명세서를 CSV 또는 TSV로 저장합니다. Excel 파일은 'CSV UTF-8'로,
  PDF 명세서는 카드사에서 CSV를 다시 내려받아 사용하세요. 첫 행은 열 이름이어야 합니다.
• 프로그램에서 '카드 명세서 월 마감' → '카드 CSV 열기'를 눌러 거래일·가맹점·금액 열과
  날짜 순서를 확인합니다. 통화 열이 없으면 기본 통화가 적용됩니다 (초기값 EUR).
  여러 카드를 사용하면 '카드 별칭'을 지정하고 같은 카드를 다시 열 때 같은 별칭을 쓰세요.
  거래는 카드 별칭·날짜·가맹점·금액·통화로 식별합니다.
• PDF 폴더를 선택하고 카드 거래를 클릭합니다. 금액·통화가 같은 PDF를
  업체명과 날짜가 가까운 순서로 볼 수 있습니다. 후보는 직접 확인 후 '선택 연결'을 누르세요.
• 다른 금액의 PDF나 여러 건을 연결하려면 '전체 PDF 표시'를 켜고 Ctrl 또는 Shift로 선택하세요.
  분할 결제와 환불은 명세서에 해당 거래를 함께 포함하면 연결된 PDF와 카드 거래의 합계를
  비교합니다. 환불은 명세서에서 음수여야 합니다. Gutschrift, Stornorechnung,
  Credit Note가 문서 머리말에 표시된 경우 환불·정정 문서로 표시합니다.
• 내용이 동일하거나 업체명과 인보이스 번호가 같은 PDF는 '중복 확인'으로 표시합니다.
  이미 다른 거래에 연결된 PDF를 다시 연결하면 확인 창이 뜹니다.
• PDF 행을 더블클릭하면 문서가 열립니다. 'Gmail 검색'은 거래일 전후 14일의
  PDF 첨부 메일을 기본 브라우저에서 찾습니다. 입력한 발신자 이메일 주소는
  해당 가맹점의 다음 검색에 자동으로 제안됩니다. Gmail 계정은 브라우저에서 선택할 수 있습니다.
• '확인 필요한 거래만'으로 미해결 항목을 확인하고, 거래에 메모를 남긴 뒤 'CSV 내보내기'로
  전체 결과를 저장할 수 있습니다. 연결과 메모는 이 Windows 계정의
  %LOCALAPPDATA%\InvoiceRenamer\monthly-close.json에 저장됩니다.
  같은 명세서와 PDF 폴더를 다시 열면 이어서 작업할 수 있고, PDF 이름을 바꾼 뒤에는
  PDF 폴더를 다시 선택하면 연결이 갱신됩니다.

새 파일명 예시: 58.39_26-11-25_greenist GmbH_Nr_R1044176_invoice.pdf
금액(EUR이 아니면 통화 포함), 발행일(연-월-일 두 자리), 업체명, 인보이스 번호, 원래 파일 이름 순서입니다.
매칭완료 폴더로 옮기면 앞에 거래번호가 붙습니다. 예: [611-001]_58.39_26-11-25_greenist GmbH_Nr_R1044176_invoice.pdf
원래 파일 이름은 %LOCALAPPDATA%\InvoiceRenamer\original-names.json에 파일 내용 기준으로 기억합니다.
이 버전으로 이미 이름을 바꾼 파일을 다시 열면 보존된 원래 이름을 사용합니다.
원래 이름을 붙인 결과가 너무 길면 확인 필요로 표시합니다.

마크다운으로 저장

첫 화면에서 PDF를 한 개 이상 선택하고 '마크다운 저장'을 누르세요.
현재 PDF와 같은 폴더에 같은 이름의 .md 파일을 UTF-8로 저장합니다.
기존 .md가 있으면 _2, _3 등을 붙입니다. 파일명을 먼저 정리하면 새 PDF 이름으로 저장됩니다.
마크다운에는 확인된 인보이스 정보와 페이지별 추출 텍스트가 들어갑니다.
PDF의 사진과 표 서식은 포함되지 않으며, 본문을 읽지 못한 페이지는 문서 안에 표시됩니다.

발행월 폴더 정리

첫 화면에서 정리할 PDF가 담긴 폴더를 선택하고 '발행월 폴더로 이동'을 켜세요.
미리보기에 2026-11 같은 대상 폴더와 파일명이 표시됩니다. 옮길 PDF를 선택하고
'선택 항목 정리'를 누르세요. 발행일이 없거나 확인이 필요한 PDF는 값을 편집한 뒤 옮길 수 있습니다.
발행일만 확인된 파일은 기존 이름으로 이동할 수 있습니다. 마크다운 파일은 이동하지 않습니다.

카드 명세서 월 마감에서 상위 PDF 폴더를 고르면 그 폴더와 바로 아래의 YYYY-MM 폴더를 함께 검색합니다.

은행·카드 명세서와 세무사 전달용 ZIP

월 마감 화면의 '은행·카드 명세서 추가'로 CSV/TSV나 거래 표가 들어 있는
텍스트 PDF를 여러 개 추가할 수 있습니다. 가능한 경우 카드사·은행 원본 CSV를
우선 사용하세요. 스캔 명세서와 추출이 불완전한 PDF는 CSV로 받아주세요.
PDF는 추출 건수, 금액, 부호를 원본과 대조하세요. 마크다운은 인보이스 검색용입니다.

같은 계좌나 카드에는 항상 같은 별칭을 쓰세요. 지출이 음수인 명세서는 가져오기
화면에서 부호 반전을 선택하세요. 마감월을 넣으면 해당 월의 거래번호를 부여하고,
비워두면 거래일의 월을 사용합니다. 예를 들어 2026년 8월은 608-001입니다.
이미 발급된 거래번호는 같은 거래를 다시 열어도 유지됩니다. 여러 명세서에서
같은 계좌·일자·거래처·금액·통화가 겹치면 확인 목록을 검토하세요.

증빙 폴더에서 PDF, XRechnung XML, ZUGFeRD PDF를 읽을 수 있습니다. 거래를
선택한 후 후보 증빙을 확인해 연결하세요. '세무사용 ZIP'에는 원본 명세서,
번호를 붙인 증빙 복사본, 독일어 대조표·증빙 정보·미연결 및 읽기 오류 목록이
들어갑니다. 공급일, 세율, 세액 등은 읽힌 경우에 표시합니다. 대조 완료는
거래와 증빙의 금액이 맞았다는 뜻입니다. 세무 검토 항목은 Belegdetails에 있습니다.

독일 American Express 월 명세서는 '은행·카드 명세서 추가'에서 해당 PDF를 고르세요.
'Umsatzdatum'은 카드 사용일이고 'Buchungsdatum'은 카드사 반영일입니다.
명세서에 표시된 'GUTSCHRIFT'는 자동으로 음수로 읽으므로 금액 부호 반전은 끄세요.
명세서 전체를 한 마감월로 번호 매기려면 가져올 때 마감월을 직접 입력하세요.

DKB 카드 명세서와 Deutsche Bank 계좌 명세서 PDF도 지원합니다.
DKB의 S/H와 Deutsche Bank의 입출금 부호는 지출을 양수로 자동 변환합니다.
이 PDF 양식에서는 가져오기 화면의 '지출이 음수인 명세서'를 '아니요'로 두세요.

매칭완료 폴더

월 마감 화면의 '매칭완료 폴더로 이동'을 누르면 금액 대조까지 끝난 증빙의 이동 위치를
미리 볼 수 있습니다. 예를 들어 11월 발행 폴더에 있는 증빙이 2026-10 마감에 연결되면
2026-11/매칭완료_2610/ 아래로 옮깁니다. 중복 증빙이나 여러 마감월에 연결된 증빙은
확인 대상으로 남깁니다. 이동한 PDF 및 XML은 월 마감 화면에서 계속 찾을 수 있습니다.
나중에 연결을 해제해도 이미 옮긴 파일은 제자리에 있습니다.

작업 이어서 열기와 일괄 확인

• 월 마감의 '이어서 작업'을 누르면 마지막 작업에 넣은 명세서, 가져오기 설정,
  증빙 폴더를 다시 읽고 확인할 거래만 표시합니다. 원본 명세서가 이동하거나
  바뀌었다면 해당 파일을 다시 추가하세요. 이전 버전에서 만든 연결은 그대로 읽을
  수 있으며, 이어서 열 목록은 새 버전에서 명세서를 추가할 때부터 기록됩니다.
• '일괄 매칭 후보'는 금액·통화와 업체명(또는 이미 확인한 가맹점 별칭)이 맞고,
  날짜 차이가 7일 이내이며 증빙이 하나로 좁혀진 거래를 보여줍니다.
  연결할 행을 Ctrl/Shift로 선택하고 확인하세요.
• '카드대금·내부이체 후보'는 계좌·카드 별칭이 서로 다르고 7일 이내에 반대
  부호로 기록된 같은 금액의 거래를 찾아줍니다. 양쪽 명세서를 열어야 하며,
  후보를 확인한 뒤 연결합니다. 거래를 선택하고 '연결 해제'를 누르면 취소할 수 있습니다.
• 첫 화면의 '정리 되돌리기'와 월 마감의 '이동 되돌리기'는 각각 해당 창을
  연 동안 수행한 마지막 작업을 복원합니다. 원래 위치에 파일이 생겼거나
  옮긴 파일이 변경된 경우 해당 파일은 복원 실패로 표시합니다.
• Amex, DKB, Deutsche Bank의 지원 PDF를 불러올 때 원본 청구·차감 합계
  또는 잔액과 추출 결과를 비교합니다. 차이가 있으면 미리보기에서 확인할 수 있고,
  계속 가져오면 세무사용 ZIP의 오류 목록에도 기록됩니다.

거래 기록, 세무사 메모, 환불

• '거래 메모·기록'에서 내부 메모와 날짜별 작업 기록을 남깁니다. 기존 거래 메모도
  내부 메모에 남아 있습니다. 외부로 보낼 문구는 '세무사 전달 메모'에 적으세요.
  자료를 기다리는 경우 후속 예정일을 입력할 수 있습니다.
• '증빙 전달 메모'는 증빙 한 장에 연결되며 해당 증빙을 내보낼 때
  세무사용 ZIP의 02_Belegdetails.csv에 포함됩니다.
• 한 거래에 영수증 여러 장을 연결하려면 거래 한 줄을 선택하고 '전체 증빙 표시'를
  켠 다음 Ctrl로 영수증을 선택하세요. 프로그램이 영수증 합계와 거래 금액을 대조합니다.
• 증빙 없이 결제·환불을 묶으려면 같은 통화의 결제 한 건과 음수 환불 한 건 이상을
  선택하고 '결제·환불 연결'을 누르세요. 일부 환불은 잔액을 확인 목록에 표시하고,
  전액 환불은 상대 거래번호와 함께 대조표에 기록합니다.

한국어 작업과 독일어 전달

• 화면, 내부 메모와 작업 기록은 한국어로 사용할 수 있습니다. 세무사에게 보낼 내용은
  '세무사 전달 메모'나 '증빙 전달 메모'의 독일어 입력란에 적으세요. 거래 메모 화면에서
  자주 쓰는 요청·추가 제출 문구를 버튼으로 넣을 수 있습니다. 자동 번역은 하지 않습니다.
  이전 버전에서 적은 한국어 전달 메모는 원래 값이 남으며, ZIP에는 번역 대기 표시가 들어갑니다.
• '배분·차액'에서 거래와 연결된 증빙을 선택해 증빙별 배분 금액과 차액 사유를 남깁니다.
  08_Betragszuordnung.csv에 배분 금액과 미배분 금액이 들어갑니다.
• '후속 목록'에서 요청 중, 기한 지남, 수신 완료, 세무사 확인 필요와 추가 전달 내역을 봅니다.
• '접대비'에서 증빙별 참석자, 업무 목적, 일자, 장소와 금액을 기록하면
  07_Bewirtung.csv에 표시됩니다.
• 세무사용 ZIP은 독일어 표와 안내를 포함합니다. 원본 파일과 업체명 등은 그대로 유지됩니다.
  ZIP을 다시 만들면 새 버전으로 저장하며 06_Nachreichungen.csv에서 이전 마감본 대비
  변경된 거래를 확인할 수 있습니다. '마감본 이력'은 로컬 작업 기록입니다.

제출 미리보기, 추가 제출과 독일어 초안

• '세무사용 ZIP'을 누르면 저장 전에 미해결 건수, 증빙, 전달 메모와 번역 대기
  건수를 확인할 수 있습니다. 미리 본 ZIP을 그대로 저장합니다.
• ZIP을 실제로 보낸 뒤 '마감본 이력'에서 해당 파일을 선택해 '전달함'으로 기록합니다.
  이후 '회신 대기', '추가 요청', '처리 완료' 등으로 갱신할 수 있습니다.
  프로그램이 메일을 발송하거나 회신을 확인하지는 않습니다.
• '추가 제출 ZIP'은 전달했다고 표시한 마감본 이후의 변경 거래와 새로 연결되거나
  전달 정보가 바뀐 증빙을 담습니다. 이미 전달한 증빙은 파일명으로 참조합니다.
  원본 명세서를 다시 보낼 필요가 있는 경우 전체 마감본을 만드세요.
• '거래 메모·기록' → '독일어 초안 미리보기'에서 한국어 기록과 거래 정보를
  확인한 다음 필요한 부분을 편집해 독일어 전달란에 넣을 수 있습니다.
  증빙 요청·수신·검토 상태와 입력한 예정일을 바탕으로 문구를 작성하며,
  자유문 전체를 자동 번역하지는 않습니다.

미분류 일괄 처리, 백업과 마감 확정

• '새 인보이스 가져오기'에서 처음에는 상위 인보이스 폴더를 고릅니다.
  그 안의 '미분류'를 검색하며, 폴더가 없으면 만듭니다. 경로를 확인한 뒤
  '정리하고 마크다운 저장'을 누르면 이름 변경, 발행월 이동과 마크다운 저장을
  한 번에 처리합니다. 필수 정보가 부족한 파일은 미분류에 남습니다.
  정리 되돌리기로 PDF를 복원할 수 있으며 이미 생성한 .md는 그대로 남습니다.
• 월 마감에서 '작업 백업'으로 거래번호, 연결, 메모와 제출 이력을 백업하세요.
  원본 증빙, 명세서 및 제출 ZIP 파일 자체는 포함되지 않습니다. 다른 PC에서
  복원할 때는 이 파일들도 옮겨야 합니다. 경로가 다르면 다시 선택하세요.
  복원하면 현재 기록을 먼저 사용자 데이터 폴더에 별도 백업으로 보관합니다.
• '월 마감 확정·재열기'에서 확정한 달의 거래, 메모 및 연결 증빙 정보를
  잠급니다. 새 증빙을 받아 변경이 필요하면 사유를 입력해 다시 여세요.
  기존 거래번호는 유지되며 확정·재열기 기록은 마감본 이력에 남습니다.
• 처음 실행하거나 '설치·작동 점검'을 누르면 폴더 쓰기, PDF 읽기,
  독일어 스캔 OCR, ZIP 쓰기를 점검합니다. 폴더를 선택한 뒤 실행하면
  그 폴더에서 직접 쓰기를 확인합니다.

겹치는 거래 검토, 수정값과 사진

• 같은 계좌·카드의 날짜, 거래처, 금액, 통화가 겹치면 가져올 때 확인합니다.
  같은 거래면 기존 번호를 유지하고, 별도 결제라면 새 번호를 생성합니다.
  같은 명세서를 다시 열면 이전 선택이 유지됩니다.
• 시작 화면에서 고친 발행일, 업체명, 금액은 내용이 같은 파일에 계속 적용됩니다.
  파일명을 바꾸거나 폴더를 옮겨도 유지되며, 이 설정은 PC의 InvoiceRenamer
  사용자 데이터 폴더에 invoice-edits.json으로 보관됩니다.
• 월 마감 창의 '전체 월 검색'에서 거래번호, 업체명, 파일명, 금액을 검색합니다.
  여러 발행월 폴더를 포함하려면 증빙의 상위 폴더를 선택하세요.
• JPG, JPEG, PNG 영수증을 미분류 폴더에 직접 넣을 수 있습니다. OCR로 읽고
  마크다운으로 저장하며 원래 이미지 확장자를 유지합니다.

인보이스 번호로 구분

원래 이름에 없는 인보이스 번호를 읽으면 새 파일명에 __번호_ 뒤로 붙입니다.
같은 업체·일자·금액의 문서도 월 마감 후보 목록의 '인보이스 번호' 열에서
구분할 수 있습니다. 번호가 비었거나 오인식된 경우 증빙을 열어 확인하고,
첫 화면의 '선택 항목 편집'에서 인보이스 번호를 입력하거나 수정하세요.

번호 대조, 나란히 보기와 정정 증빙

• 거래 설명에 인보이스 번호나 주문번호가 있으면 금액·통화가 맞는 증빙 후보
  중 번호가 일치한 것을 먼저 보여줍니다. 연결은 후보를 확인한 뒤 선택하세요.
• 거래를 선택하고 '나란히 보기'를 누르면 왼쪽에 거래 상세, 오른쪽에 증빙 첫
  페이지가 표시됩니다. XML은 주요 항목을 표시합니다.
• 정정 증빙을 골라 '정정·원본 연결'에서 원본을 선택하세요. 월 마감 ZIP의
  09_Rechnungskorrekturen.csv에 원본과 정정 증빙 번호를 기록합니다.
  거래에 직접 연결된 문서가 증빙 파일로 들어가며, 연결은 거래 금액을 바꾸지 않습니다.

증빙과 명세서 누락 점검

• '미연결 증빙'은 어느 거래에도 연결되지 않은 증빙을 모아 보여줍니다.
  행을 골라 미결제, 다른 결제수단, 다음 달 확인으로 분류할 수 있습니다.
• '명세서 기간 점검'은 계좌·카드 별칭별로 가져온 기간을 표시합니다.
  Amex, DKB, Deutsche Bank PDF에서 읽은 명시적 기간 사이의 빈 구간과 겹침을
  확인할 수 있습니다. CSV 등은 관측한 거래일만 표시하며 누락 판정에 쓰지 않습니다.
  이전에 가져온 자료는 다시 열거나 '이어서 작업'으로 다시 읽을 때부터 기간을 기록합니다.
• 증빙이 없는 거래에 '명세서 근거 표시'를 사용하면 은행 수수료, 카드 연회비 등
  사유를 기록할 수 있습니다. 증빙 요청 목록과 구분되며, 독일어 ZIP에서
  세무사 검토 대상으로 사유를 확인할 수 있습니다.

보조 자료 첨부, 월별 누락 점검표, 전체 작업 백업

• 거래를 선택하고 '보조 자료 첨부'를 누르면 PDF, 사진, 이메일 파일(.eml),
  TXT, CSV, XML을 첨부할 수 있습니다. 프로그램이 파일의 사본을 관리합니다.
  제출 ZIP의 Anlagen 폴더와 10_Anlagen.csv에 거래번호별로 들어갑니다.
  이 메뉴는 제출용 보조 자료이며 내부 기록은 '거래 메모·기록'에 남기세요.
• '월별 누락 점검표'는 증빙 없는 거래, 거래 없는 증빙, 독일어 번역 대기,
  세무사 확인과 명세서 기간 공백을 집계합니다. 월을 선택해 상세 내용을 봅니다.
• 증빙의 상위 폴더를 열고 '전체 작업 백업'을 생성하면 프로그램 기록과 확인 가능한
  명세서, 증빙, 마크다운, 보조 자료, 수정값 및 제출 ZIP을 묶습니다. 빠진 파일은
  백업 결과에서 확인하세요. 이전 버전에서 경로를 기억하지 못한 명세서는 다시
  불러와야 묶을 수 있습니다. '전체 작업 복원'은 선택한 위치에 새 폴더를 만들고
  경로를 연결하며 현재 기록은 별도 백업으로 남깁니다.
  전체 백업은 내부 메모도 포함하는 본인 보관용입니다.

윈도우 설치용 파일, 금액 표기와 원본 위치 확인

• 함께 제공하는 InvoiceRenamer-Setup.cmd는 64비트 Windows용 설치 파일입니다.
  실행하면 사용자 앱 폴더에 프로그램을 설치하고 시작 메뉴에 바로가기를 추가합니다.
  필요하면 Python을 공식 사이트에서 받아 서명을 확인한 뒤 함께 설치합니다.
  첫 실행은 Python 구성 요소와 OCR 언어 다운로드를 위해 인터넷이 필요합니다.
  ZIP을 직접 사용하는 경우 압축을 모두 풀고 기존처럼 Start.bat을 실행하세요.
• ZIP과 설치 폴더의 Beispiele에는 테스트용 영수증 PDF와 카드 CSV가 있습니다.
  증빙 폴더는 Beispiele/Belege, 명세서는 Beispiele/Karte.csv를 선택하면 됩니다.
• 58,39와 58.39를 같은 금액으로 읽으며, 독일어 1.234,56도 처리합니다.
  파일명에는 점을 계속 사용합니다. 세무사용 CSV 금액에는 독일식 소수점 콤마를
  사용하고, Abgleich.xlsx에는 계산 가능한 숫자 셀을 사용합니다.
• 세무사용 ZIP을 모두 푼 다음 Abgleich.xlsx를 열면 독일어 대조표와 증빙 탭이
  표시됩니다. 한 거래의 증빙이 여러 개라면 Belege 탭에서 각 파일 링크를 열 수 있습니다.
• '선택 항목 편집'이나 '나란히 보기'의 '원본 위치 확인'을 누르면 PDF 또는 사진에서
  같은 날짜·총액·인보이스 번호의 위치 후보를 확인합니다. 같은 숫자가 여러 곳에
  있으면 앞뒤 문구와 함께 비교하세요. 원본 파일 자체는 수정하지 않습니다.

계좌·카드 설정 기억, 여러 명세서 가져오기와 요청 메일

• 명세서의 열을 설정해 가져오면 해당 양식과 계좌·카드 별칭에 맞춘 날짜 열,
  통화, 날짜 순서, 부호 설정을 기억합니다. 다음 명세서를 열 때 설정과 별칭을
  확인하세요. 마감월은 매번 확인하거나 비워두면 거래일 기준으로 적용합니다.
• '여러 명세서 추가'에서 CSV·PDF를 함께 고르면 파일별 건수와 검산 결과가
  표시됩니다. 설정이 없거나 재확인이 필요한 파일은 행을 더블클릭해 설정하세요.
  검토를 끝낸 파일을 선택해 한 번에 가져올 수 있습니다.
• 거래를 선택하고 '인보이스 요청 초안'을 누르면 거래처, 거래일, 독일식 금액을
  넣은 독일어 메일을 편집·복사할 수 있습니다. 메일을 직접 보낸 뒤 '보낸 뒤 요청
  완료 기록'을 눌러 해당 날짜와 요청 중 상태를 저장할 수 있습니다.

버전, 연습 모드, 오류 진단

• 창 제목에서 버전을 볼 수 있습니다. 새 InvoiceRenamer-Setup.cmd로 기존 설치를
  업데이트하면 교체 전에 프로그램 소스와 작업 기록 JSON을 사용자 데이터 폴더의
  update-backups에 보관합니다. 원본 증빙, 첨부 자료와 명세서를 함께 보관하려면
  월 마감의 '전체 작업 백업'을 사용하세요.
• 이전 버전으로 돌아가려면 프로그램을 닫고 설치 폴더의 Restore-PreviousVersion.cmd를
  실행하세요. P는 이전 프로그램만 복원하고, B는 백업에 있던 작업 기록 JSON도
  복원합니다. 복원 직전 상태도 별도 백업으로 남습니다.
• '연습 모드 열기'는 별도 창을 띄워 예시 증빙의 복사본과 임시 작업 기록을
  사용합니다. 월 마감 창에서 '예시 명세서 불러오기'를 누르면 매칭과 ZIP 저장을
  연습할 수 있습니다. 연습 기록은 창을 닫으면 삭제되고, 별도로 저장한 ZIP은 남습니다.
• '오류 진단 저장'은 프로그램·Python 버전, 오류 단계, 오류 종류와 시스템 오류 번호를
  기록합니다. 거래, 문서 내용, 메모, 파일 경로 및 오류 원문은 기록하지 않습니다.

v1.2에서 바뀐 점

• 색 의미: 초록=대조 완료·정상, 보라=이체·환불, 주황=확인 필요, 빨강=증빙 없음·필수 누락, 회색=인보이스 아님 의심.
• 1단계에서 발행일·업체명·총액·인보이스 번호를 못 읽으면 빨간색 '필수 누락'으로 알려 줍니다.
  더블클릭해 직접 입력하세요. 250 EUR 이하 영수증은 번호가 없어도 주황색(소액영수증 확인)으로만 표시합니다.
• 인보이스가 아닌 것 같은 PDF·사진은 회색으로 표시합니다. 선택 후 '더보기 → 인보이스 아닌 파일 → 제외 폴더'을 누르면
  같은 폴더의 '제외' 폴더로 옮겨집니다(삭제하지 않음).
• 프로그램을 열면 시작 화면이 먼저 나오고, 준비되면 창이 맨 앞으로 옵니다.
  이미 열려 있을 때 다시 실행하면 새 창 대신 열려 있는 창을 앞으로 가져옵니다.

v1.1.1에서 바뀐 점

• 파일명 변경 화면에 XRechnung XML(.xml)도 표시됩니다. ZUGFeRD/Factur-X PDF는 안에 든 XML 정보를 먼저 사용합니다.
• 총액 표기가 Gesamtbetrag, Zahlbetrag, Summe, Total 등인 인보이스도 읽습니다. 기존에 읽히던 표기가 있으면 그 값을 우선합니다.
• 자주 받는 업체를 머리글로 알아보게 하려면 %LOCALAPPDATA%\InvoiceRenamer\seller-patterns.json 파일에
  {"^\\s*Muster GmbH\\b": "Muster GmbH"} 처럼 적어 두세요.
• 새로 불러오는 독일 은행 CSV에서 독일어 글자(ä, ö, ü 등)가 한글로 깨지던 문제를 고쳤습니다.
  이미 불러온 명세서는 거래번호와 연결을 지키기 위해 이전과 같은 방식으로 읽습니다.
• EXE판(InvoiceRenamer.exe)은 설치 없이 실행되며 작업 기록은 설치판과 같은 위치를 사용합니다.
